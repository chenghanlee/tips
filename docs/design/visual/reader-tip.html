Ask for a written plan before letting the agent touch a large refactor

by ada Published Sep 20, 2026 Updated Sep 22, 2026
Technique: Planning Model: Claude Opus 5.5 Environment: Claude Code
Tried this? Write a review

On any change that touches more than three modules, I ask the agent for a numbered plan first and read it before it edits anything. Most bad refactors I have seen were visible in the plan: a module it planned to delete, or a test it planned to "simplify".

Steps:

  1. Paste the prompt below with the goal filled in.
  2. Reply with corrections to the plan, not to code.
  3. Say "go" only when every step names a file and a test.
